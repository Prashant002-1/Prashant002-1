[Hermes JobApps](https://github.com/Prashant002-1/hermes-jobapps)  
A local-first job-application cockpit built around Hermes Agent, SQLite, structured tools, LaTeX materials, contacts, follow-ups, and approval gates. The point is not more chat. The point is state.

[Personal Canvas Agent](https://github.com/Prashant002-1/Personal-Canvas-Agent)  
A HackRamapo-winning assistant for Canvas workflows, built around tool-calling, persistent memory, semantic search, and safer agent behavior over course data.

[PBrain](https://github.com/Prashant002-1/pbrain)

A research thread on ambiguous user intent and recommendation behavior. I use it as a way to study how systems should handle messy asks without pretending they are clean.
